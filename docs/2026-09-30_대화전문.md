사용자가 직접 고르는 건 **"내 제품이 뭐냐"** 하나로 줄이는 걸 추천합니다. 인증 구분(안전인증·안전확인 등)은 고르게 하지 말고 시스템이 정해서 보여줘야 합니다. 마지막 세부품목은 카드 여러 개로 **편하게 고르게 하되, 결과는 반드시 하나로 확정**해야 합니다. 형제 세부품목끼리 라벨 항목이 대부분 달라서, 대충 골라도 결과가 같은 구조가 아닙니다.

#### 근거 (두 가이드북에서 직접 센 숫자)

| | 생활용품 | 전기용품 |
|---|---|---|
| 분류 크기 | 품목 72개 | 대분류 약 12개, 중분류 178개, 세부품목 408개 |
| 인증 구분이 정해지는 방식 | 품목만 알면 정해짐. 예외는 가구 하나(높이 762 mm 이상 서랍장만 따로) | 같은 제품이 **조건에 따라 갈리는 경우 29개** |
| 세부품목 선택이 필요한 곳 | 16개 품목만(최대 헬스기구 7개). 나머지 56개는 품목이 곧 세부품목 | 거의 전부 |
| 형제 세부품목끼리 라벨 항목이 같은 비율 | 16개 중 3개 | 79개 중 거의 같음 24, 비슷 32, 다름 23 |

- 전기에서 인증 구분을 가르는 조건은 세 가지입니다.
  - 전원 방식: 콘센트(교류)인지, 충전·건전지(직류)인지
  - 전압: 교류 30 V 이하, 직류 42 V 이하인지
  - 소비 전력(정격입력): 1.5 kW 이하인지
- 예를 들어 커피분쇄기는 콘센트형이면 안전인증, 직류형이면 안전확인입니다. 전기드릴은 콘센트형이면 안전확인, 충전식이면 공급자적합성확인입니다.
- 사용자는 대부분 "안전확인"이 뭔지 모릅니다. 대신 "충전식이에요?"에는 바로 답할 수 있습니다.
- 형제 비교는 제가 자동으로 대조한 대략치입니다.

#### 설계 원칙 3가지

1. **분기(선택 단계)는 "가이드북의 어느 페이지를 쓸지" 정할 때만 씁니다.** 그 안의 작은 차이는 분기가 아니라 입력 칸을 켜고 끄는 질문으로 처리합니다. 걱정하신 예외 케이스 대부분이 여기서 해결됩니다.
   - 수입품이면 수입자명·제조국명 칸을 켭니다.
   - 드럼 포장이면 회전방향 칸을 켭니다.
   - 에어매트리스면 경고문구 칸을 켭니다.
2. **인증 구분은 사용자가 고르는 게 아니라 결과로 보여줍니다.** "인증서와 다르면 바꾸기" 버튼만 둡니다.
3. **분류표는 코드에 박지 않고 데이터(품목 표)로 둡니다.** 가이드북이 2021년 판이라, 새 판이 나오면 표만 갈아 끼우면 되도록 합니다.

#### 흐름

**0단계, 공통 입구**
- **범위 확인:** 전기로 작동하는지 물어서 전기용품과 생활용품 워크플로우로 나눕니다. 어린이용(만 13세 이하)·식품·화장품·생활화학제품·무선기기는 두 가이드북 밖이라 안내만 하고 끝냅니다. 이 경계는 법령 확인이 한 번 필요합니다.
- **지름길:** KC 인증서, 신고증명서, 시험성적서가 있으면 올리게 합니다. 팀이 정한 Gemini가 품목·인증 구분·모델명·정격을 읽고, 바로 확인 단계로 건너뜁니다. 실제 판매자는 대부분 인증서를 이미 갖고 있어서 이 길이 주 경로가 될 수 있습니다. 다만 안전기준준수 품목은 서류가 없어서 이 길을 쓸 수 없습니다.

**전기용품 워크플로우**
1. **제품 찾기:** 검색창을 먼저 두고(예: "커피 그라인더"), 대분류 12개 둘러보기는 보조로 둡니다. 중분류 178개는 목록으로 보여주기엔 너무 많습니다.
2. **후보 카드 3~5개:** 각 카드에 세부품목 이름, 적용범위 한 줄, "라벨에 더 들어가는 것"을 보여줍니다. 가이드북에 "기타 전기기기" 같은 실제 페이지가 있으니, "기타 ○○" 카드를 항상 함께 둡니다.
3. **조건 질문:** 앞의 29개 품목만 전원 방식, 전압, 정격입력을 묻습니다. 나머지 약 380개는 이 단계를 건너뜁니다.
4. **입력:** 공통 뼈대(정격·A/S 연락처 포함), 품목별 추가 항목, 조건부 칸을 채웁니다.
5. **라벨 생성과 검증**

**생활용품 워크플로우**
1. **제품 찾기:** 검색창과 함께, 72개 품목을 사용자가 아는 묶음으로 둘러보게 합니다. 예를 들면 스포츠·레저, 고령자용품, 미용·위생, 주방·생활, 자동차용품, 가구·인테리어입니다. 가이드북처럼 인증 구분 순서로 보여주지 않습니다.
2. **세부품목 카드:** 16개 품목에서만 나옵니다(2~7개 중 선택).
3. **조건 질문:** 사실상 가구의 높이 762 mm 질문 하나입니다.
4. **인증 구분 자동 결정:** 안전기준준수면 KC 칸을 자동으로 뺍니다.
5. **입력하고 생성**

사용자가 고르는 횟수는 전기가 최대 검색 1번 + 카드 1번 + 질문 2~3개, 생활은 대부분 검색 1번으로 끝납니다.

#### "마지막엔 러프하게 고르게 할까"에 대한 답

화면은 편하게, 결과는 정확하게 가야 합니다.
- **카드마다 차이를 보여줍니다.** "이 제품이면 라벨에 ○○, ○○가 추가돼요"를 적어서 사용자가 자기 제품과 대조하게 합니다.
- **"잘 모르겠어요" 버튼을 둡니다.** 누르면 후보를 가르는 질문 하나로 좁힙니다. 예: 헬스기구에서 "벨트 위를 걷거나 달리나요?"에 예라면 러닝머신입니다.
- **항목이 사실상 같은 형제는 한 카드로 묶습니다.** 예: 전동보드 3종은 사용연령·최대하중이 같습니다. 품목 표를 만들 때 "묶어도 되는 형제"를 표시해 두면 됩니다.
