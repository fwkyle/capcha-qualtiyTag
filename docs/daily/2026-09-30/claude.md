## 3. 가이드북 분류 트리 시각화 (표본 13개)

- 결과물: "표시사항 분기 지도" 페이지 https://claude.ai/artifact/GBjKgqfFxiAF5YsXxNBZ3M (비공개, 원본은 세션 임시 폴더). 전기 6개·생활 7개 세부품목을 인증 구분 → 품목 → 세부품목 트리로 그리고, 누르면 라벨 미리보기가 나온다.
- 확인한 구조
  - 라벨 = 공통 뼈대 + 인증 표시(KC) + 세부품목별 추가 항목.
  - 공통 뼈대가 둘로 갈린다. 전기: 제품명·모델명·정격·제조년월·제조자명(수입자명)·A/S 연락처·제조국명 + KC 규격 표시사항. 생활: 제품명·모델명·제조연월·제조자명·수입자명·주소 및 전화번호·제조국명.
  - 생활용품 안전기준준수 24쪽은 전부 KC 마크·번호 자리가 없다(나머지 인증 구분은 전부 있음).
  - 전기용품 일부(예: 전기레인지 PDF 60쪽)는 추가 항목을 "KC 60335-x 7항에 따른다"로만 적는다. 생성기 데이터는 가이드북만으로 부족하고 KC 규격 원문이 필요하다.
  - 세부품목 페이지 수: 생활 107(안전인증 10·안전확인 51·공급자적합성확인 22·안전기준준수 24), 전기 438(안전인증 155·안전확인 172·공급자적합성확인 111). "적용기준"이 있는 쪽을 센 추정치.
